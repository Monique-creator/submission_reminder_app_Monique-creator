# About submission_reminder_app

The application is a basic reminder tool, which can be utilized to keep track of submissions of student assignments. It begins by setting up an environment script, which sets up the required folders and files of the project. The configuration file will specify the assignment name, number of days left before the deadline, among others. When launched with the help of a startup script, the app loads this configuration and loads some additional helpful functionality into it before proceeding to execute the main reminder process. The message reminds a list of students and their status of submission of the work on a text file, verifies who has and who has not submitted the work before the deadline, and then displays a message with the list of students who have not submitted their work before the deadline. On the whole, the app is supported by joining these minute fragments to enable easy and systematic assignment tracking.
