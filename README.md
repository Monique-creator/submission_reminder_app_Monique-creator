# About submission_reminder_app
# This is an application that gives notifications to the students who have outstanding assignments on the upcoming deadline to avoid missing the assignment. 
The project contains a number of files and directories that render it operational. The environment is created with the help of the create environment.sh script, and the Submission Reminder App is launched with the help of startup.sh script. 

The copilot shell script.sh will enable one to update the assignment name in the config/config.env. The main reminder is found in app/ directory, student submission data is found in submissions.txt in the assets/ directory, assignment data is in config.env in the config/ directory, and helper functions are found in modules/ directory.

# This application, when run, allows a student to find the days remaining for the assignment to end.
